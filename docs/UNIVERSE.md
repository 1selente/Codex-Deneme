# Universe Policy

The repository starts with a small liquid-symbol watchlist for engineering validation, not a claim that the list equals the current BIST 100.

Why:
- BIST index membership changes over time.
- Using today's constituents for old history creates survivorship/selection bias.
- A trustworthy historical BIST 100 backtest needs point-in-time constituent membership.

The MVP therefore proves ingestion, validation, signal generation, journaling and alerts on a small list first.

Before any result is described as a "BIST 100 backtest", add a documented point-in-time membership source and tests for constituent effective dates.
