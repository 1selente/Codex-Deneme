# Backtest Audit

Inspect:
- look-ahead
- survivorship/selection bias
- corporate actions
- execution timing
- spread/slippage despite zero configured commission
- benchmark
- sample/trade count
- train/validation/locked-OOS separation
- multiple testing and parameter mining
- liquidity/microstructure limitations

Never improve a result by quietly changing assumptions.
