# Paper Trading

Record signal identity, timestamps, feature snapshot, reason codes, next-bar fill assumption, slippage, D1/D3/D5/D10 outcomes, MFE and MAE.

Enforce idempotency.

Forbidden:
- broker integration
- order creation
- automatic real-money execution
